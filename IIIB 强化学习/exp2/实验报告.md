### 2.2 任务 1：蒙特卡罗期望值估计与 MC Basic 算法

#### 2.2.1 随机变量期望值的蒙特卡罗估计 (投币实验)

通过投掷一枚正面向上的概率为 $p=0.5$ 的硬币，生成 $N=1000$ 个样本。使用直接平均和增量更新两种方式进行期望值估计。

*   **增量平均更新公式**：
    $$w_{k} = w_{k-1} - \frac{1}{k}(w_{k-1} - x_k)$$
*   **实验结果**：
    在 $N = 1000$ 次投掷后：
    *   真实期望值 $\mu = 0.500000$
    *   直接平均估计值: $0.497000$（误差: $0.003000$）
    *   增量平均估计值: $0.497000$（误差: $0.003000$）
    *   **最大差异**：$9.99 \times 10^{-16}$（在浮点数精度误差范围内完全一致）。
*   **大数定律验证**：
    随着样本数量 $N$ 的增加，估计值逐渐收敛于真实期望 $\mu = 0.5$，误差呈现锯齿状波动下降趋势。在双对数坐标系下，估计误差曲线紧密围绕并平行于 $O(1/\sqrt{N})$ 理论收敛速度线，验证了大数定律。

#### 2.2.2 MC Basic 算法实验结果与分析

MC Basic 算法在 $r_\text{forbidden} = -1$ 的网格环境中运行，分别测试了回合长度（Horizon）$H \in \{1, 2, 3, 4, 5, 14, 15, 30, 100\}$ 下的表现。

*   **收敛迭代次数与状态值分析**：

| 回合长度 $H$ | 收敛外循环次数 | 起点 (0,0) 的最终估计状态值 | 最优策略表现 |
|:---:|:---:|:---:|---|
| $H=1$ | 1 | 0.00 | 无法收敛至目标，策略全是原地或随机 |
| $H=2$ | 2 | 0.00 | 仅目标附近的格子能获得正向价值 |
| $H=3$ | 3 | 0.00 | 传播距离增加，但 (0,0) 依然为 0 |
| $H=4$ | 5 | 0.00 | 仅下半区部分格子收敛，价值未传播到 (0,0) |
| $H=5$ | 6 | 0.00 | 价值传播范围进一步扩大，但 (0,0) 依然未被激活 |
| $H=14$ | 8 | 0.48 | 价值基本传满全图，但 (0,0) 刚好可感知 |
| $H=15$ | 8 | 0.48 | 成功收敛，(0,0) 价值为 0.48，生成正确绕行策略 |
| $H=30$ | 8 | 0.48 | 成功收敛，价值矩阵与 $H=15$ 相同 |
| $H=100$ | 8 | 0.48 | 成功收敛，与 $H=30$ 的收敛轨迹完全一致 |

*   **回合长度 $H$ 对算法的影响**：
    *   **$H$ 较小时**：由于采样回合过早被截断，远期未来的奖励（终点的 $+1$）根本无法通过折扣传播到远距离的起点。因此，左上角等远离终点的格子估值均为 $0$，导致智能体无法学习到全局导航策略。
    *   **$H \ge 15$ 时**：$5 \times 5$ 网格的最长无环路经（从 $(0,0)$ 绕行至 $(4,4)$）约为 8 步。因为 $H \ge 8$，远期奖励可以完全回传。在本实验中，当 $H \ge 14$ 时，全图状态价值成功苏醒，最终收敛出一条指向右下角最优路径的导航策略。

### 2.4 三种算法的综合对比分析

在相同的网格环境（$r_\text{forbidden} = -10.0$）下，对 **MC Basic** ($H=30$)、**MC Exploring Starts** 和 **MC ε-Greedy** 进行了 5000 回合对比：

    *   **MC Basic**：由于是按状态-动作对顺序评估（每轮迭代需要跑 $24 \times 4 = 96$ 个完整回合），它的策略更新非常缓慢。从曲线可以看出，其 RMSE 呈“阶梯式”下降，每过 96 回合才有一次跳变。

    *   **MC ε-Greedy（动态衰减）** 表现最优，大约在 150 回合即完全稳定在最高累计回报，且因为后期探索率下降，曲线没有任何震荡，非常平稳。

## 三、 思考与问题回答

### 3.1 任务 1 思考题

**问题：为什么 MC Basic 算法需要直接估计动作值（Action Value）而非先估计状态值（State Value）？**

**回答**：
在无模型（Model-Free）强化学习中，环境的**状态转移概率 $P(s'|s, a)$ 是未知的**。
如果算法只估计了状态值 $V(s)$，在进行策略改进（Policy Improvement）时，我们必须通过以下公式选择动作：
$$\pi(s) = \arg\max_{a} \sum_{s'} P(s'|s, a) \left[ R(s, a, s') + \gamma V(s') \right]$$
因为不知道 $P(s'|s, a)$，智能体即使知道每个状态的身价 $V(s')$，也无法推算出在当前状态 $s$ 采取哪个动作 $a$ 会转移到好的状态。
相反，如果直接估计动作价值 $Q(s, a)$，策略改进公式变为：
$$\pi(s) = \arg\max_{a} Q(s, a)$$
该公式**完全不需要环境转移模型**，只需查表比较当前格子上 4 个方向的 $Q$ 值大小即可。因此，无模型蒙特卡罗算法必须直接估计动作值。

### 3.2 任务 2 思考题

#### 问题 1：首次访问（First-visit）和每次访问（Every-visit）方法在样本利用上有何区别？各自的优缺点是什么？

**回答**：
*   **首次访问（First-Visit MC）**：在一个回合中，如果某个状态-动作对 $(s, a)$ 被多次访问，只有**第一次访问**时计算的后续折扣回报 $G_t$ 会被存入该 $(s, a)$ 的样本列表。
    *   *优点*：各样本的回报在统计上是独立的，估计值是无偏估计。
    *   *缺点*：在一个长回合中，后面重复访问的数据全部被“抛弃”，数据利用率低。
*   **每次访问（Every-Visit MC）**：在一个回合中，每次访问到 $(s, a)$，都分别计算从该时刻起直到回合结束的累计回报 $G_t$，并全部计入更新。
    *   *优点*：充分利用了单次轨迹中的所有状态转移数据，样本效率高，收敛更快。
    *   *缺点*：同一回合内多次访问的样本之间存在强烈的自相关性，前期可能会引入轻微的估计偏差，但在大样本极限下依然渐进无偏且收敛。

#### 问题 2：Exploring Starts（探索起点）条件在实际应用中存在什么问题？MC ε-Greedy 算法是如何解决这个问题的？

**回答**：
*   **Exploring Starts 存在的问题**：它要求智能体可以**在环境的任意状态、采取任意动作作为游戏的起点**。在现实世界的许多任务中，这几乎是不可能的。例如：控制直升机飞行，我们无法让直升机凭空在半空中（危险状态）以某一特定倾角开始运行；或者在自动驾驶中，我们不能要求车辆直接在“即将撞墙”的边缘状态随机开始。
*   **MC ε-Greedy 的解决方案**：它放弃了对“初始状态”的强行要求（可以从同一个固定起点开始）。取而代之的是，它在**动作选择上引入了 ε 概率的随机探索**。由于智能体在每一步都有 ε 的概率瞎走，这种随机性确保了智能体在长期的轨迹中，能够以非零概率游历到地图上的所有格子，从而完成了对整个状态-动作空间的探索。

#### 问题 3：为什么当 ε 较大时，最优 ε-Greedy 策略可能与最优贪婪策略不一致？

**回答**：
因为在 ε-Greedy 算法中，动作价值 $Q(s, a)$ 估计的是**当前 $\epsilon$-greedy 策略本身**的价值，而不是贪心策略的价值。
如果 $\epsilon$ 较大（例如 $\epsilon = 0.5$），这意味着智能体有一半的时间在随机乱晃（频繁撞墙或踩禁止区）。
*   在估计 $Q(s, a)$ 时，由于后续步骤有一半概率走错，原本极佳的格子 $s$ 的价值会被后续的随机碰撞拖累，导致 $Q(s, a)$ 严重偏低。
*   相反，那些远离危险区但离终点也较远的平庸格子，由于不容易撞墙，其动作值反而显得比危险边缘的最优格子更“安全”。
这导致最终提取出的贪心策略避开了最优路径（因为最优路径需要贴着禁止区域走，容错率低），收敛到了保守的次优策略。

#### 问题 4：简述 MC Basic、MC Exploring Starts、MC ε-Greedy 三个算法之间的递进关系。

**回答**：
1.  **MC Basic**：最基础的尝试。它直接套用 DP 的策略迭代，必须为每一个 $(s, a)$ 手动生成独立回合，效率极其低下。
2.  **MC Exploring Starts (改进数据效率)**：不再为每个状态-动作对单独生成 episode。它随机选一个起点，然后把整条长轨迹上遇到的所有 $(s,a)$ 都拿来更新 Q 表（利用 every-visit），大幅提高了数据效率。但它仍然需要“硬性改变起点”的Exploring Starts假设。
3.  **MC ε-Greedy (改进探索方式，面向实用)**：彻底去掉了 Exploring Starts 这一不切实际的假设。它使用 ε-greedy 策略本身来进行持续的在线探索，使得算法可以从任意单一起点出发，真正成为一个在实际应用中可用的无模型控制算法。

## 四、 核心代码与分析

### 4.1 样本均值增量更新（`coin_flip.py`）

```python
# 增量平均迭代逻辑
incremental_means = np.zeros(N)
w = 0.0 # 初始估值
for k in range(1, N + 1):
    x_k = samples[k-1] # 当前新样本（0或1）
    # w_k = w_{k-1} - 1/k * (w_{k-1} - x_k)
    w = w - (1.0 / k) * (w - x_k)
    incremental_means[k-1] = w
```
*   **公式对应**：代码中 `w = w - (1.0 / k) * (w - x_k)` 严格对应了增量更新公式 $w_k = w_{k-1} - \alpha_k (w_{k-1} - x_k)$，其中步长 $\alpha_k = 1/k$。
*   **优势**：该实现仅保存了当前步数 $k$ 和当前均值 $w$，不需要开辟内存来存储全部历史样本，空间复杂度降为 $O(1)$。

### 4.2 MC Exploring Starts 核心回溯更新（`mc_exploring_starts.py`）

```python
# 每次访问蒙特卡罗评估 (every-visit)，从后往前计算
G = 0.0
for s_t, a_t, r_tp1 in reversed(trajectory):
    # 贝尔曼期望回溯：G_t = R_{t+1} + γ * G_{t+1}
    G = r_tp1 + env.gamma * G
    
    # 增量更新 Q 表平均值
    N[s_t, a_t] += 1
    Q[s_t, a_t] += (1.0 / N[s_t, a_t]) * (G - Q[s_t, a_t])
    
# 策略改进：对所有状态选择最大 Q 的动作
for s in env.get_non_terminal_states():
    policy[s] = np.argmax(Q[s, :])
```
*   **输入输出**：输入为轨迹列表 `trajectory`，输出为更新后的值表 `Q` 和策略 `policy`。
*   **回溯机制**：利用 `reversed(trajectory)` 实现了从后往前的 $G$ 值计算，避免了为每个时间步重复进行向前求和的操作，时间复杂度由 $O(T^2)$ 优化为 $O(T)$。

## 五、 总结与体会

通过本实验，我深刻理解了蒙特卡罗方法在“无模型”强化学习中的基石地位。值迭代和策略迭代属于“上帝视角”（已知环境模型），而蒙特卡罗方法则是“实践出真知”——通过不断地在环境中尝试（采样），利用大数定律，将实际获得的回报均值作为期望的估计。

我最深刻的体会有两点：
1.  **探索（Exploration）的代价**：在 ε-Greedy 实验中，虽然高 ε 保证了地图的充分探索，但也由于随机性“污染”了动作值函数，导致即使收敛也无法拿到最高分；而低 ε 甚至 0 探索则导致算法直接陷入局部死胡同。这生动地体现了强化学习中探索与利用（Exploration vs Exploitation）的经典矛盾。
2.  **动态衰减的艺术**：通过引入动态衰减的 ε 策略，我们在前期（一无所知时）保持极高的探索率，让智能体走遍地图；在后期（策略基本成型时）逐渐减小探索率，专注于利用学到的最优路径。这种“先探索，后收敛”的思路在很多实际复杂的强化学习系统中依然是不可或缺的黄金法则。
